# Nuvex AI 0.4.0

Cloud Access vervangt de Cloudflare-instellingen in Nuvex. Activeer met een checkbox en kies het cloudserver-adres, standaard https://cloud.nuvexai.nl. Tijdelijke HTTPS-adressen worden ondersteund.

Registratie, accountsynchronisatie en opnieuw verbinden gebeuren automatisch. Uitschakelen verwijdert de lokale sleutel en verbinding. Cloudbediening op afstand is nog niet beschikbaar.

Nieuwe installatie: pak de volledige ZIP uit en start Start Nuvex AI.bat op Windows. De setup installeert de benodigde Node-afhankelijkheden. Op Linux: installeer Node.js, voer npm install uit en start met npm start.

Bestaande installatie: stop Nuvex, kopieer de inhoud van de update-ZIP naast package.json en start opnieuw. Gebruikers, wachtwoorden en bestaande systeemconfiguratie zijn niet opgenomen.

JavaScript-syntax, de Cloud Access-tests en de bestaande tests voor navigatie, sliders, swipe en weerstatus worden voor publicatie gecontroleerd. Deze versie is nog niet op de Pi of in een browser getest.
