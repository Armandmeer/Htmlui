NUVEX login media
- background-4k.jpg = current high-resolution static background.
- background.mp4 = optional animated background. If present, login/setup automatically use it.
Recommended MP4: H.264, 3840x2160 or 1920x1080, muted, seamless loop.
To return to static mode, remove background.mp4.
The HTML form is separate from the background so it remains fully functional.
